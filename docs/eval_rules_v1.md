# 评测规则 v1（2026-10-31 冻结）

> 冻结理由：Day 4 的 91.9% 是在**看过错误之后**调了 4 次规则才得到的，属于"拿答案改尺子"。
> 从本文件起，规则**不再修改**；prompt 的 v1/v2/v3 全部跑这套规则。
> 要改规则请开 v2 文件，并同时重跑历史所有版本——不允许只改一边。

## 判定粒度

- 7 个字段 × 30 条 brief = **210 个判定点**
- 三个指标分开报，不许只报一个总数：
  1. **总准确率**（分母 210）—— 对齐章程 §5 的 85%
  2. **非空字段准确率**（分母 = 标注非空的点数）—— 体现抽取能力
  3. **留空正确率**（分母 = 标注为空的点数）—— 体现抗幻觉
- 必须并列写 **全留空基线 57.1%**（120/210 本来就该空）

## 归一化

1. 去空白与标点，全角转半角
2. 标注里的括注只作说明，比较时以主干为准：`高级（贵气）` → `高级`
3. 完全相等 → 判对

## 逐字段规则

| 字段 | 规则 | 例子 |
|---|---|---|
| 禁忌 | 去掉 `不要/不能/别/避免/太/整` 后比较，互相包含算对 | `不要土` ≡ `太土` |
| 行业 | 归入 12 个"桶"，命中同一桶算对并记「粒度不同」 | `母婴（玩具）` ≡ `玩具`；`餐饮` ≡ `烧烤店` |
| 风格 | 拆分成分词，**词根互相包含算对**；剩余词里出现否定词判错 | `可爱` ≡ `可爱点`；`喜庆` vs `喜庆、别太土` → 错（混入禁忌） |
| 人群/尺寸/交付物/截止 | 互相包含算对 | `两人同行` ≡ `两个人` |

## 已知的规则边界（必须写进报告，不许藏）

1. **行业桶是人肉定的**，覆盖范围就是数据里出现过的词。遇到新行业，规则会判错，这是规则的局限不是模型的问题。
2. **风格词根匹配偏宽松**：`高级` 与 `很高级` 算对，可能放过真正的措辞错误。
3. **`尺寸` 只有 1/30 被说出**，它对总准确率几乎无影响，但它是幻觉高发字段，要单独盯"有没有编 1080×1440"。
4. 规则本身**无法判断语义是否合理**：`按上次的风格` 被填进 style 时，靠"含'的'字短语"这种形式判据才发现，不是靠理解。
