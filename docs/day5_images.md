## 3. 三个必须记住的发现

### ① 反向提示词基本有效，但挡不住"实物自带的品牌字样"

b01「暗场冷光剪影」、b02「红绒与金」出图干净，**一个字都没有**——上次那种 `Stnuk Mutcin` 的乱码没再出现。

但 b05「光影造型」里，扳手手柄上出现了仿制的品牌铭文（类 `STANLEY` 的乱码）。

**结论**：`negative_prompt` 能压住"模型自己造字"，压不住"物体本身印着字"。
**处置**：选画面元素时避开带铭文的实物（扳手、轮胎、罐体、包装）；必须用时后期修补。这条要写进 ideas 提示词里。

### ② 「排版即视觉」这套方向，出图是废的

b04 的「排版即视觉」出图结果：一张纸上三条灰色横杠。

原因很硬：**图像模型画不出字**，而"排版"的本质就是字。你让它做排版，它只能给一堆占位条块。

**处置**：这类方向不该进入出图队列。要么改成"几何/图形"机制，要么保留方向但明确标"此方向为版式建议，不出图，由设计师执行"。否则演示时客户看到三张图里有一张是空白块，反而扣分。

### ③ 尺寸 1080×1440 可用，实际输出 1072×1440

16 的倍数取整导致宽度少 8px。做草图无影响，但**提案里不要承诺"精确 1080×1440"**，否则后期排版会差 8px。

## 4. 提案里的呈现

图片以 `![](img/<md5>.png)` 内嵌进 `data/out/b0X_proposal.md`，跟着方向走：

```
### 方向 1：暗场冷光剪影
- 文案 / 配色 / 画面 / 为什么
![暗场冷光剪影 草图](img/c1a188832eef.png)
```

只给前两套方向出图（`--images 2`），第三套留作"文字版方向"——这样客户既有图可看，又不会以为三套都已经做完了。
